# QMOF 正式 LLM corpus

- 训练：`train.jsonl`，18,335 个材料，311,695 条。
- 验证：`val.jsonl`，2,037 个材料，34,629 条。
- 合计：20,372 个材料，346,324 条；每材料 16 条具体任务 QA＋1 条 description。没有另建 test.jsonl。
- 实际训练使用 messages 和对应几何结构；metadata 包含原始答案和来源，不能作为模型输入。

## 结构在哪里

- `structures/` 保存全部 20,372 个纯几何 CIF；文件名是 qmof_id。本次逐个核对存在性、文件哈希、原子数和允许字段，复用之前通过全部往返检查的导出文件。
- train.jsonl / val.jsonl 每行顶层 cif_path 是绝对路径，cif_relative_path 相对于本目录。geometry_sha256 是原始 JSON 几何哈希，不是 CIF 文件字节哈希。
- `structure_index.jsonl` 提供每个 CIF 的 cif_sha256、来源和往返验证；不包含新的模型对话。
- 所有原子显式列出，只有恒等对称操作；不含计算后原子属性、化学式汇总、体积或实际空间群标签。不要把这种写法误当真实 P1 对称性。

## 划分和重复结构

- 先按结构匹配连通组分组，再划分约 90% train / 10% val，最后展开任务；同一材料和匹配组不会跨划分。
- 同约化组成内比较 2,992 对结构，找到 15 对相近结构、0 对严格等价结构。相近记录不删除、不平均或改写标签，只约束同一划分。
- LLM4Mat 重叠的 1,526 个材料全部固定在 train；其匹配组的其他成员也固定在 train。真实 membership 标记不扩散到这些邻居。
- `split_manifest.jsonl` 记录每个材料的 split、structure_group_id 和固定训练原因；`structure_groups.json` 记录比较范围、容差和匹配边。不同组成类似物及其他数据集的全面去重不在本轮范围。

## 模板与描述

- 固定随机种子 20260910。每个 split、每个任务分别均衡分配 8 条 query；具体任务的 3 条 response 也均衡分配。文件记录顺序另行随机打乱。
- description 每材料只有一条：先均衡选五类，再均衡抽类内模板；不是每材料生成 15 条。组合和实际引用字段都记录在元数据中。
- 电子性质统一 PBE，热力学用配套来源；方法仅在元数据。回答保持单位及每晶胞/每原子口径，不含 system、CIF 字样或结构占位符。显示位数不代表计算准确度。

## 检查与预览

- `preview.jsonl` 和 `preview.md` 是同一批 47 条真实 train/val 记录，覆盖 16 类具体任务和全部 15 条 description 模板，不是独立生成的演示。
- `build_report.json` 记录最终数量、模板分布、CIF 检查、全量逐条回读验收和输入/输出哈希。
- 所有检查针对结构—字段—问答对应和划分泄漏；没有重新做 DFT、Zeo++ 或凸包计算。原始库及 paired_audit 主表未修改。
