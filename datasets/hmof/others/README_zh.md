# hMOF LLM Corpus

## 用哪些文件

- `train.jsonl` 是训练语料，共 **534,879 条**。
- `val.jsonl` 是内部验证语料，共 **28,153 条**，不是 LLM4Mat 原始官方验证/测试集。
- 共 **563,032 条问答、70,634 个严格结构组和独立 CIF 文件**。
- `structures/` 按文件 SHA256 的前两位分目录存放结构。每条语料都有 `cif_path`、`cif_relative_path`、`cif_sha256` 和 `geometry_sha256`。
- `preview.md` 与 `preview.jsonl` 是从本次实际语料直接抽取的同一批样例，不是旧预览或重新编造的样例。

## 如何生成

每个可用单项孔隙性质生成一条；CO₂ 可用时生成一条单点和一条五压力点问答；描述可用时生成一条组合描述。没有把每个结构和所有模板做笛卡尔展开。

| 模板组 | train | val | 合计 |
|---|---:|---:|---:|
| 最大孔腔直径 | 67,098 | 3,532 | 70,630 |
| 孔限制直径 | 67,100 | 3,532 | 70,632 |
| 氦空隙率 | 66,872 | 3,521 | 70,393 |
| 可达比表面积 | 67,001 | 3,525 | 70,526 |
| 总比表面积 | 66,985 | 3,525 | 70,510 |
| CO₂ 单点 | 66,362 | 3,493 | 69,855 |
| CO₂ 五压力点 | 66,362 | 3,493 | 69,855 |
| 组合描述 | 67,099 | 3,532 | 70,631 |

64 个基础 query、32 个 response，保留 7 个科学任务、8 个模板组。每个模板组及 split 内自然简问与条件完整问法数量差不超过 1；8 个 query 和4个 response 的使用数量差也不超过1。
单点压力在 0.01、0.05、0.1、0.5、2.5 bar 之间均衡分配。没有压力的自然 CO₂ 问法只用于五点任务，不随机挑一个压力数值冒充唯一答案。
描述在六种已批准字段组合之间均衡分配，先选该结构全部有合格标签的组合，再同时填入问题和回答。回答的每个数值都来自该结构已审核的字段。

## 输入与回答

`messages` 只有 user 与 assistant，不含 system、CIF 文本、结构占位符或英文冒号。结构由消息外的路径字段关联，条件、标签来源和模板 ID 留在 metadata 或 provenance 中。
自然简问可以不带探针或温度，但回答会明确采用的条件。氦空隙率是 298 K 的氦空隙率；两种面积均使用氮探针半径 1.86 Å，单位 m²/g；CO₂ 是 298 K 的纯组分吸附，单位 mol/kg。
不使用 BET、饱和容量、插值曲线、实验观察、可合成性或稳定性等没有相应标签支持的解释。

## 来源与边界

结构直接复制主表所引用的 MOFX 官方压缩包内 CIF 字节，没有重新写出、修改坐标或理想化结构。
CO₂ 用原研究对应的官方模拟标签；五项孔隙性质用 MOFX Consistent Set 的重算标签。此次生成没有重新运行 Zeo++、Widom、GCMC 或 DFT。
原审核主表及原始数据没有修改。待审、隔离和每个结构被暂停的任务均不进入语料。
保持原审核主表的 train/val，已知潜在 QMOF 重叠标记保留且相关可用组留在 train。这不是按拓扑家族划分的外推评估集，也不代表完成了所有其他语料的近重复排查。

## 验收与追溯

所有问答均重新读取，与固定计划、冻结模板和审核标签逐条重建比较；全部结构文件重新校验字节哈希。另以 ASE 对按原子数分层选取的24个结构进行独立解析及周期几何比对。
`structure_index.jsonl` 给出每个结构的来源成员、哈希、split、全部来源 ID 和标签来源信息。
`provenance/templates.json` 保存实际使用的模板快照，`provenance/task_schema.json` 保存科学定义；自然问法的条件放置以模板快照中的新版规则为准。
`build_report.json` 包含完整数量、采样分布、源文件及语料哈希、软件版本和验收结果。
数字按主表保留，不靠取整消除冲突。`cif_sha256` 是文件字节哈希，`geometry_sha256` 是解析后未取整的元素/分数坐标/晶胞对象哈希，二者含义不同。
移动语料目录后应使用 `cif_relative_path`，原绝对路径不会自动更新。

生成器位于上一级 `build_hmof_corpus.py`。命令 `python build_hmof_corpus.py build` 创建新语料；已有完整输出时不会覆盖。命令 `python build_hmof_corpus.py verify` 可重新验收已有语料。
