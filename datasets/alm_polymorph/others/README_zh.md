# ALM polymorph 训练语料

本目录语料已生成并通过逐条验收。
训练 13,677 条，验证 669 条，共 14,346 条，独立结构文件 10,922 个。

## 使用文件
- train.jsonl 用于训练，val.jsonl 用于验证。
- preview.jsonl 是正式语料中的原样记录，覆盖两个任务子组及无能量组的正反方向。
- 结构在 structures 目录，输入输出路径分别写在 input_cif_path 和 output_cif_path。
- 相对路径字段 input_cif_relative_path 和 output_cif_relative_path 以本目录为根，移动目录后优先使用。
- messages 只有 user 和 assistant，不含系统消息、文件格式名称、冒号、结构全文或结构占位符。
- 训练加载器需按独立路径字段接入结构表示，不能只读取文字就忽略结构。

## 任务与方向
- 两组分别为只生成同组成的不同晶型，以及额外要求凸包上方能量更低。每组二十条问题和十条响应。
- 两组在各划分内等比例分配，问题与响应分别均衡抽样，数量差不超过一。
- 每个通过语料划分检查的原始结构对只生成一条对话，不按模板组合扩量。
- 无能量组正反方向均衡随机选择，能量组只保留高能到低能。固定种子 20260913。
- 反向时结构、路径、来源标识及逐端性质同步交换，差值按当前输出减输入重算。
- metadata.energy 只记录核实的上游字段，无能量组不把这些字段加入消息。
- 原始行号与原方向证据只作追溯，不用原始行 ID 中的四位小数作为能量真值。

## 划分与保留
- 原有科学配对审核通过 200,899 对，本次 186,553 对因划分保护暂不进入语料，不意味着科学配对审核失败。
- excluded_from_corpus/split_holds.jsonl 保存这些配对的原行号及原因，原始数据和通过集合未修改。
- 保留既有 CSP、atomtxt、doping 的划分，严格几何、来源身份和结构对关系形成的完整连通组不拆开。
- 与原始 ALM eval 相连、连接旧 train 和 val，或几何比较未解决的整个候选连通组暂缓。
- 仅对没有已有划分约束的新连通组作固定种子的九比一分组，最终记录比例不保证为九比一。
- 保护范围为本地 ALM 既有语料和原始 eval，不声称完成其他项目语料或任意近似结构的全局泄漏检查。

## 验收范围
- 每个结构文件回读核对组成、晶胞和元素坐标对应，每条语料检查来源配对、模板、方向、路径及能量元数据。
- 原始完整配对审核由冻结校验和复用，本次未重新运行 DFT 或把能量降低解释为真实相变与实验稳定性。
- 结构文件仅写几何和恒等对称操作，不泄露性质标签，也不宣称材料物理空间群为 P1。
- verification.json 是验收记录，build_report.json 保存完成状态与文件校验和。
- 上一级筛选报告是生成前的冻结历史证据，其未生成语料标记不改写。
