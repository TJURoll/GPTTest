AtomWorldBench 输出文本模板（Standalone Response）
================================================

设计目标
--------
1. user 和 assistant 的最终文本均不出现文件格式名称、文件路径、输入/输出结构标签或结构占位符。
2. user 只包含填好参数的动作指令；assistant 只包含一条填好参数的完整回复。没有 system 消息。
3. 回复独立成句，不使用 “The resulting structure is:” “Here is the structure:” 等等待后续结构内容的表达。
4. 实际输入与输出结构由独立字段或模态传递，并保持和同一条记录配对；不能用文字确认代替真实结构输出。
5. 仅覆盖当前启用的 12 种动作：AddAtomAction、ChangeAtomAction、DeleteAroundAtomAction、DeleteBelowAtomAction — Excluding、InsertBetweenAtomsAction、MoveAtomAction、MoveSelectedAtomsAction、MoveTowardsAtomAction、RemoveAtomAction、RotateAroundAtomAction、SuperCellAction、SwapAtomsAction。
6. DeleteBelow-Including、MoveAroundAtomAction 和训练池中禁用的 InsertBetweenAtoms bench wording 不参与训练模板采样，不据此恢复隔离数据。
7. 本文件中的参数槽位仅用于构建回复，必须填入对应原始 action_prompt 中提取的参数；最终消息不得残留任何未填槽位。
8. 参数原样保留，不重算、不改写精度；{displacement}、{axis}、{cartesian_coordinate}、{atom_indices} 等列表保留完整格式，重复参数必须一致。
9. 所有原子索引均指操作前输入结构中的零基原子顺序，不将删除、插入或重排后的输出索引当成输入索引。
10. 保留建议比例：25% GENERAL、75% ACTION-SPECIFIC；各池内部 4 条模板等比例抽取，回复抽样与 user 模板抽样独立。
11. 动作专属模板覆盖对应动作的全部参数；通用模板不需要参数。回复只陈述配对数据支持的编辑，不添加稳定性、能量、性质改善或额外计算结论。
12. 不加入 “Okay”, “Sure”, “Successfully”, “We did ...” 等填充词；所有回复以句号结束。

GENERAL [25%]
================================================

The requested structural modification has been applied.

The structure has been updated according to the requested operation.

The specified structural edit has been completed.

The requested operation has been applied to the structure.

建议的实际采样规则
================================================

1. 每条训练记录仍只生成一条 user 消息和一条 assistant 消息，不因回复模板数量而复制记录。
2. user 模板继续从对应动作/子组的 5 条启用模板中等比例分配，并用固定种子随机打乱。
3. assistant 的 GENERAL/ACTION-SPECIFIC 目标比例为 25%/75%；记录数不能整除时用整数配额近似，不直接依赖独立伯努利抽样实现比例。
4. 在对应的回复池中均衡分配 4 条模板，再随机打乱；回复抽样使用独立随机流，不把某条 user 模板固定绑定到某条 assistant 模板。
5. ACTION-SPECIFIC 只按当前动作选择。SuperCell 的 5 个 user 子组共用本文件的 12 组回复，分别保留原始三个复制倍数。
6. 将原始参数完整填入选定模板；不要重新计算坐标、距离、角度或元素，不把位移改写为终点坐标。
7. 生成后的两条消息都不得包含文件格式名称、输入/输出结构占位符、未填参数槽位、结构正文、路径或要求后续结构文本的冒号式引导。
8. 原始指令、参数、来源位置、结构路径和哈希可以保留在 metadata 中，但不能拼入 user 或 assistant 的文本。
9. 实际输入和输出结构继续通过独立字段或模态配对传递；加载输入结构时必须保持原子顺序。
10. 此采样比例只规定训练语料。评估记录仍独立保存、不混入训练；若将其转成新格式，其消息也必须满足相同的无格式名、无占位符要求。
11. 上述说明、标题、参数清单和采样规则都不是回复模板，不能混入消息文本。


================================================
语义边界与检查
================================================

- GENERAL 共 4 条，12 种动作各 4 条，共 52 条回复模板。
- DeleteAround 必须包含中心原子，邻域距离为周期最小镜像距离，且严格小于半径；四条回复均保留半径参数。
- DeleteBelow 仅为 Excluding，比较操作前输入结构的 Cartesian z，不做周期包裹后再比较；保留参考原子和同高度原子。
- InsertBetween 使用两原子的直接 Cartesian 线段，不是无限延长线或最短周期镜像线段。
- MoveTowards 使用初始位置给出的直接 Cartesian 方向，并施加完整位移；允许越过目标，不声称距离必然缩短指定数值。
- RotateAround 的选择使用周期最小镜像距离且严格小于半径，旋转轴通过中心原子、方向向量为 Cartesian 表示，遵循右手规则；旋转使用输入结构中相对中心的直接 Cartesian 位移，不先替换为最小镜像位移。
- SuperCell 的三个整数是沿晶格矢量 a、b、c 的复制倍数，不是长度；回复里的乘号仅为展示，不改变参数。
- 动作专属回复填入的参数集合必须完整，与对应原始动作一致；相同参数的所有重复位置必须一致。
- 文本确认不等于额外科学验证，不新增“结构稳定”“能量降低”“性质改善”之类结论。
