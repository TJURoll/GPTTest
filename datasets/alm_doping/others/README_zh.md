# ALM doping 训练语料

状态为已生成并通过逐条验收。
共 6,928 条对话，训练 6,403 条，验证 525 条，独立结构文件 9,098 个。

## 使用文件
- train.jsonl 用于训练，val.jsonl 用于验证。
- preview.jsonl 是上述实际语料中的五条记录，不是重新生成的另一套示例。
- 结构文件在 structures 目录，输入输出路径分别记录在 input_cif_path 和 output_cif_path。
- input_cif_relative_path 和 output_cif_relative_path 相对于本 llm_corpus 目录，移动目录后优先使用相对路径。
- messages 只有 user 和 assistant，不含系统消息、格式名称、冒号、结构全文或结构占位符。
- 消息不含结构数据，训练加载器应按独立路径字段注入对应结构表示。

## 生成规则
- 只使用此前通过筛选的 6,928 个有向结构对，每对一条，不按模板组合复制扩量。
- 一个全位点元素替换任务子组，五条问题和五条响应，在各划分内独立均衡抽取，数量差不超过一。
- 保留已有 train 和 val 归属，仅对新增完整结构连通组按固定种子 20260912 做 9∶1 分组划分，不保证最终记录比例恰为 9∶1。
- 同组结构、两个端点和相同来源 ID 不跨训练验证划分；此前关联原始 eval 或跨旧划分的候选没有重新纳入。
- 纯几何结构文件使用显式位点和恒等对称操作，不额外写入性质标签；这不声称材料物理空间群为 P1。
- 输入输出仍是来源中的结构，不通过移动原子制造新答案；左手原始晶胞仅作有记录的整数换基。
- 不声称真实弛豫、稳定性或性质改善。来源结论仍限于已核对的保存版本，不代表全量当前弃用状态已查完。

## 验收与保留
- 所有结构文件回读核对组成、晶胞、元素与坐标对应，所有结构对重新验证编辑见证。
- verification.json 保存逐条验收汇总，build_report.json 保存输出校验和，split_manifest.jsonl 保存组划分。
- 原始数据、已有 CSP/atomtxt 的 llm_corpus 和上一级筛选预览均未改写。
- 上一级 release_check.json 是生成前的冻结筛选报告，其未生成状态是历史状态，本目录的 build_report.json 表示本次已完成。
